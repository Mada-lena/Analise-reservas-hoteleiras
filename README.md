

📊 Análise de Reservas Hoteleiras | Power BI

Projeto de análise de dados desenvolvido para compreender o comportamento das reservas hoteleiras, o desempenho comercial, a sazonalidade, os cancelamentos e o perfil dos clientes.

A análise foi realizada no Power BI, utilizando Power Query para preparação dos dados e DAX para criação das métricas e indicadores.

---

🎯 Objetivo do projeto

O objetivo é transformar dados de reservas em informações que possam apoiar decisões relacionadas a:

- desempenho das vendas
- canais de reserva.
- evolução da receita.
- comportamento dos clientes.
- sazonalidade da procura.
- cancelamentos.
- desempenho por país.
- identificação dos principais clientes.

---

❓ Perguntas de negócio

A análise procurou responder às seguintes perguntas:

- Como evoluiu o volume de reservas ao longo dos anos?
- Quais canais de venda geram maior receita?
- Quais países apresentam maior volume de reservas e receita?
- Quais períodos concentram maior procura?
- Qual é o comportamento dos cancelamentos?
- Quais clientes representam maior participação na receita?
- Quais funcionários apresentam maior volume de vendas?
- Qual é a receita média gerada por reserva/passageiro?

---

🛠️ Tecnologias utilizadas

- Power BI Desktop — visualização e análise dos dados
- Power Query — tratamento e transformação dos dados
- DAX — criação de medidas e indicadores
- Excel / CSV — fontes dos dados

---

🔄 Etapas do projeto

1. Preparação dos dados

Os dados foram tratados no Power Query, incluindo:

- organização das tabelas.
- tratamento de tipos de dados.
- transformação de campos.
- preparação das informações para análise.
- relacionamento entre diferentes fontes de dados 

2. Modelagem

Foi estruturado um modelo de dados para permitir a análise das reservas por diferentes dimensões, como:

- período.
- país.
- cliente.
- funcionário.
- canal de venda.
- reserva.

3. Criação das métricas

Foram utilizadas medidas DAX para calcular indicadores como:

- receita total.
- número de reservas.
- receita média por reserva.
- participação na receita.
- evolução anual.
- ranking de clientes.
- indicadores relacionados aos cancelamentos.

4. Visualização

O dashboard foi construído para permitir uma análise interativa do desempenho das reservas e dos principais indicadores comerciais.

---

📈 Principais insights

Crescimento das vendas

Foi identificado um crescimento de aproximadamente 50% nas vendas entre 2023 e 2024, indicando uma evolução positiva do desempenho analisado no período.

👥 Principais clientes

Os clientes com maior contribuição para a receita foram identificados através de ranking, permitindo visualizar a concentração do faturamento nos principais clientes.

🌍 Análise por país

A distribuição das reservas e da receita por país permite identificar os mercados com maior participação no negócio.

📅 Sazonalidade

A análise temporal permite identificar períodos de maior concentração de reservas, informação que pode apoiar o planeamento da operação hoteleira.

👨‍💼 Desempenho dos funcionários

Foi analisada a receita associada aos funcionários responsáveis pelas vendas, permitindo comparar o desempenho comercial individual.

📊 Receita média

Foi calculada a receita média por reserva/passageiro para compreender melhor o valor gerado pelas reservas realizadas.
