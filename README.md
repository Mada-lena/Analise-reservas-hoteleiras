# 📊 Dashboard de Vendas e Reserva 
*Projeto de Análise de Reservas de Hotéis

Este projeto apresenta uma análise detalhada de reservas hoteleiras, focando em faturamento por canal de venda, pais , ano e  comportamento de cancelamento . O dashboard foi desenvolvido no **Power BI** como parte do aprendizado com o Professor Jilson Santana.*

## 🎯 Objetivo
Analisar o desempenho de vendas anual, identificar os clientes VIPs e entender os picos de demanda (sazonalidade).

## 📈 Insights Gerados
- **Vendas por Ano:** Identificamos um crescimento de 50% entre 2023 e 2024.
- **Receita por funcionario:** Os funcionarios com  maiores  faturamento de vendas.
- **Sazonalidade:** O período de Novembro/outono concentra o maior volume de reservas, sugerindo reforço de check-in nesta época.
- **Receita por Passageiro:** Calculamos a média de receita gerada por cada check-in.
-  **Eficiência de Canais:** Maior margem de lucro por  cada canal de venda .
-  **Receita por País:**  Receita total de reserva por país.
-  **Top Clientes:** Os 10 maiores clientes que representam 30% do faturamento total.

## 🛠️ Tecnologias Utilizadas
- Power BI Desktop
- Linguagem DAX (para cálculos de medidas)
- Power Query (limpeza de dados)
